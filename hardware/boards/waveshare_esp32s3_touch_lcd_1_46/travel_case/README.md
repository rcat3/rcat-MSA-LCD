# Travel Case for the 1.46" Housing

A hinged case that carries the [1.46" housing](../) with the board in it, so the display is protected in a bag.

## Files

- `travel_case_1_46.stl` - All five parts laid out to print: the bottom, the lid, the hinge, the clasp and the hinge pin.

Inside, the case has a round pocket 52.4 mm across and 21.4 mm deep, which fits the housing with about 0.3 mm to spare.  It's the 1.28" display's travel case with the lid's pocket made 2.6 mm shallower, because the 1.46" housing is shorter.  Nothing else changed, so the hinge, clasp and pin are the same as the original's.
